# SkyCine TV — Samsung Smart TV (Tizen OS)

Полноценная кинематографическая версия **SkyCine** для телевизоров **Samsung Smart TV** на базе **Tizen OS**.

Приложение разработано с использованием собственного аппаратного плеера **Samsung AVPlay (`webapis.avplay`)**, оптимизированного интерфейса под пульт ДУ (D-Pad Spatial Navigation), виртуальной клавиатуры и полной поддержки совместного просмотра (Watch Together).

---

## 🌟 Ключевые возможности

1. **Собственный аппаратный плеер Samsung AVPlay (`webapis.avplay`)**:
   - Аппаратное ускорение чипсета Samsung TV с прямым выводом на видеоплан (Zero-Copy overlay).
   - Поддержка **4K UHD, HDR10, HEVC/H.265, H.264, VP9**.
   - Аппаратное воспроизведение многоканального звука **DTS, Dolby Digital AC3, E-AC3, AAC, MP2**.
   - Переключение звуковых дорожек на лету.
   - Автоматический переход к следующей серии (Countdown).
   - Резервный HTML5 видеоплеер для отладки в браузере на ПК.

2. **Адаптация под пульт (D-Pad Spatial Navigation)**:
   - Полная регистрация системных клавиш пульта Samsung через `tizen.tvinputdevice`.
   - Навигация стрелками (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Enter`, `Return / Back`).
   - Быстрая непрерывная перемотка (±10 сек по стрелкам влево/вправо без потери фокуса).
   - Кинематографическая золотая подсветка фокуса (`CinemaGold`) с легким зумом (`scale-105`).

3. **Интерфейс в стиле SkyCine**:
   - **Главная (Home)**: Большой Hero-баннер с автопостером, полка «Продолжить просмотр», полка медиатек, новинки и популярные тайтлы.
   - **Фильмы и Сериалы (Catalog)**: Сетка постеров с фильтрацией по библиотекам, рейтингом TMDB и индикатором качества.
   - **Карточка фильма / сериала (Detail Modal)**: Выбор сезонов (1, 2, 3...) и горизонтальная полка серий с превью-скриншотами, названиями и прогрессом.
   - **Поиск (Search)**: Интегрированная экранная клавиатура (RU/EN) для удобного ввода с пульта.
   - **Смотреть вместе (Rooms)**: Подключение к комнатам синхронного просмотра по коду.
   - **Настройки (Settings)**: Выбор адреса сервера, выбор движка плеера (AVPlay vs HTML5), режим масштабирования (FIT, STRETCH, ZOOM).

## 🚀 Запуск и разработка на ПК

В проект встроен виртуальный симулятор пульта Samsung Smart TV (в правом нижнем углу экрана), благодаря чему приложение можно запускать и полноценно тестировать на компьютере в обычном браузере.

```bash
# Перейдите в папку проекта
cd D:\SkyCine-TizenTV

# Запустите локальный сервер разработки
npm run dev
```

Откройте в браузере адрес `http://localhost:5174`.

## 📦 Сборка и упаковка в `.wgt` для Samsung TV

Для генерации готового виджета для Tizen OS выполните:

```bash
# 1. Сборка проекта
npm run build

# 2. Упаковка в SkyCine-TizenTV.wgt
npm run package:wgt
```

В корне проекта будет создан файл:
**`D:\SkyCine-TizenTV\SkyCine-TizenTV.wgt`**

## 📺 Установка на телевизор Samsung Smart TV

### Способ 1. Установка через Tizen Studio / SDB (Рекомендуется)
1. Включите **Developer Mode** на телевизоре Samsung:
   - В меню приложений введите код `12345`.
   - Включите **Developer Mode: ON** и укажите IP-адрес вашего компьютера.
   - Перезагрузите ТВ долгим удержанием кнопки включения на пульте.
2. Подключитесь к телевизору через консоль `sdb`:
   ```bash
   sdb connect <IP_АДРЕС_ТЕЛЕВИЗОРА>
   ```
3. Установите приложение:
   ```bash
   sdb install D:\SkyCine-TizenTV\SkyCine-TizenTV.wgt
   ```

### Способ 2. Установка через USB-флешку
1. Отформатируйте флешку в FAT32.
2. Создайте в корне флешки папку `userwidget`.
3. Скопируйте файл `SkyCine-TizenTV.wgt` в папку `userwidget`.
4. Вставьте флешку в USB-порт телевизора Samsung — появится системное уведомление об установке приложения.
